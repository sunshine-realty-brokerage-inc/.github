# Getting Support

This organization's repositories are for internal use by Sunshine Realty Brokerage Inc.

| Need                                  | Where to go                                                      |
| ------------------------------------- | ---------------------------------------------------------------- |
| Bug or problem in a project           | Open an issue in that repository using the **Bug report** form   |
| New feature or improvement            | Open an issue using the **Feature request** form                 |
| Repository or organization access     | Contact your team lead or an organization owner                  |
| Security vulnerability or data leak   | Follow the [Security Policy](SECURITY.md). **Never use a public issue.** |
| General or business inquiries         | [sunshinerealtybrokerage.ca](https://sunshinerealtybrokerage.ca) |

When asking for help, include what you were trying to do, what happened, and any error
messages. Remove passwords, tokens, and client information first.
